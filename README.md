# GEOG5990

Do health promoting neighbourhoods have loewr neighbourhood churn in Manchester?

Background and context:


Data used:
CDRC Residential Mobility Index
- the proportion of households that have changed between a year (going back to 1997) and the beginning of 2023
- it is useful in this analysis for representing the neighbourhood 'churn' as it is represented as small geographical scale (LSOAs) and it allows for more short term analysis (over 5 years) as opposed to relying on census data which is collected every 10 years
- it is estimated based on administrative and consumer datasets including electoral registers, consumer registers and land registry house sale data
